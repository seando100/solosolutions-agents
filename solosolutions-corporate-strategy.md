## Executive Summary

SoloSolutionsAI is a portfolio company building AI-powered intake and client management SaaS products for solo practitioners across multiple professional verticals. Each product — branded as Solo[Profession]AI — delivers 24/7 AI intake (chat + phone), branded client communications, marketing tools, and bilingual support, purpose-built for independent professionals who lack dedicated staff.

The company's competitive moat is threefold:
1. **Solo-practitioner focus** — every competitor targets teams, firms, and enterprises. We own the solo niche.
2. **Multi-channel AI intake** — chat, form, and phone (via Vapi) in a single platform. No competitor offers all three at our price point.
3. **Automated vertical expansion** — an AI agent workforce that spins up new verticals in days, not months, then markets and supports them autonomously.

**First product:** SoloLawyerAI (in testing, March 2026).
**Corporate domains:** solosolutionsai.com (umbrella), sololawyerai.com, solovetai.com, solorealtorai.com.

## Mission

Empower every solo professional to deliver enterprise-grade client experiences — without enterprise overhead, staff, or budget.

## Market Opportunity

### Why Solo Practitioners?

Solo practitioners represent the largest underserved segment across professional services. They share universal pain points:
- **Missed leads** after hours and on weekends
- **No dedicated intake staff** — they are the staff
- **Manual, inconsistent intake processes** that lose information
- **Limited marketing capability** — no time or budget for content creation
- **Technology tools priced for firms**, not individuals

These pain points are identical across professions. The intake schema changes; the problem doesn't.

## AI Agent Workforce

SoloSolutionsAI operates with three autonomous agent teams, built on the Claude Agent SDK with MCP integrations. These teams replace traditional headcount for engineering, marketing, and support functions.

### Team 1: Vertical Spinup Agents

Purpose: Take a profession name and produce a fully deployed, live SaaS product.

| Agent | Role | Tools |
|-------|------|-------|
| Schema Architect | Researches profession, generates intake field schema, validation rules, bilingual labels | Claude API, web research |
| Copy Agent | Generates all landing page copy, email templates, FAQ, onboarding text | Claude API, brand guidelines |
| Codebase Cloner | Forks SoloLawyerAI repo, swaps profession-specific constants, updates naming | GitHub API, file system |
| Infra Agent | Creates Supabase project, runs migrations, configures secrets, deploys to Vercel, wires DNS | Supabase CLI, Vercel CLI, DNS API |
| Vapi Agent | Creates Vapi voice assistant with profession-specific prompt, provisions phone number | Vapi API |
| QA Agent | Runs end-to-end intake flow, verifies DB rows, checks email delivery | Playwright, Supabase MCP |

**Output:** "SoloVetAI is live at solovetai.com. Here's your test login."

**Estimated spinup time per vertical:** 2-3 days (vs. 2-4 weeks manual).

### Team 2: Marketing Agents

Purpose: Automatically launch and manage marketing campaigns for each vertical.

| Agent | Role | Cadence |
|-------|------|---------|
| Content Writer | SEO blog posts, articles targeting profession-specific long-tail keywords | On launch + weekly |
| Social Media Agent | Facebook, Instagram, LinkedIn posts tailored to where the profession is active | On launch + 3x/week |
| Ad Creative Agent | Meta + Google ad copy, headlines, descriptions, A/B variants | On launch + monthly refresh |
| Ad Manager Agent | Sets up campaigns in Meta Business Suite + Google Ads, manages budget, pauses underperformers | On launch + daily monitoring |
| SEO Agent | Monitors keyword rankings, identifies content gaps, recommends new articles | Weekly scan |
| Review Solicitor | Triggers review request emails (G2/Capterra) after X days of active product use | Event-driven |
| Analytics Agent | Aggregates ad spend, signups, trial conversions, churn; delivers weekly summary | Weekly digest |
| Competitor Watch | Monitors competitor pricing, features, new market entrants per vertical | Bi-weekly scan |

**Trigger:** Vertical Spinup Complete → Marketing Orchestrator receives vertical config → all marketing agents activate.

**Human-in-the-loop:** Ad spend approval, pricing changes, customer-facing copy review (initially).

### Team 3: Support Agents

Purpose: Handle customer support autonomously across all verticals.

| Agent | Role | Trigger |
|-------|------|---------|
| Triage Agent | Reads inbound support emails, classifies priority + category (billing, technical, onboarding, feature request) | Every inbound email |
| Tier 1 Responder | Answers common questions autonomously — setup help, feature explanations, password resets | Triage routes |
| Bug Detective | On technical issues, checks Supabase logs, Vercel deployment status, edge function errors, Resend delivery | Triage flags as technical |
| Onboarding Coach | Proactively contacts new signups who haven't completed setup (no logo, no questions, no test intake) | Day 1, 3, 7 post-signup |
| Churn Prevention | Detects warning signals — no logins in 10 days, zero intakes this month, failed payment — sends re-engagement | Daily scan |
| Feedback Collector | Post-resolution satisfaction survey; aggregates feature requests into ranked backlog | Post-resolution |
| Escalation Agent | Packages full context (logs, user history, issue details) and routes to founder when Tier 1 can't resolve | When autonomous resolution fails |

**Cross-vertical advantage:** All verticals share the same infrastructure (Supabase, Vercel, Resend, Vapi), so support agents don't need retraining per vertical. FAQ content is ~80% identical; only profession-specific terminology changes.

Team 3: Support Agents 7 Agents

The Support Team handles all customer-facing support, proactive onboarding, churn prevention, and technical diagnostics. Because every vertical shares the same infrastructure (Supabase, Vercel, Resend, Vapi), support agents work across all verticals without retraining.

Cross-vertical efficiency: “How do I update my logo?” is the same answer whether the customer is a lawyer, a vet, or a realtor. The Support Team learns once and supports everywhere.

Agent Function Trigger Monthly Cost
Triage Agent Reads every inbound email to support@solo[x]ai.com via Gmail API. Classifies each ticket by priority (urgent, normal, low) and category (billing, technical, onboarding, feature request, general question). Routes to the appropriate agent or, if escalation is needed, packages context for the founder. Every inbound email $1–3
Tier 1 Responder Handles common questions autonomously using a knowledge base built from the product FAQ, help docs, and prior resolved tickets. Answers questions like “How do I change my logo?”, “Where is my intake link?”, “How do I connect Calendly?”, “Can I customize my intake questions?” Sends professional, branded responses from support@. Routed by Triage $2–5
Bug Detective When a technical issue is reported, automatically investigates before escalating. Checks Supabase edge function logs for errors, verifies Vercel deployment status, checks Resend email delivery logs, queries the database for the customer’s recent intake records. Packages diagnostic findings into a clear summary so the issue can be resolved in minutes, not hours. Triage flags as technical $2–5
Onboarding Coach Proactively monitors new signups. If a customer hasn’t completed key setup steps within 1, 3, or 7 days (uploaded logo, configured intake questions, run a test intake), sends a personalized nudge email with step-by-step instructions and a direct link to the setup they’re missing. Goal: maximize activation rate. Day 1, 3, 7 post-signup $2–5
Churn Prevention Runs a daily scan for at-risk customers. Warning signals: no login in 10+ days, zero intakes this month, failed payment, declining usage trend. Sends tailored re-engagement emails based on the specific risk signal. For payment failures, triggers a gentle “update your card” reminder before the account is suspended. Daily scan $3–6
Feedback Collector After a support ticket is resolved, sends a brief satisfaction survey (1–5 rating + optional comment). Aggregates feature requests from survey responses and support conversations into a ranked backlog, weighted by frequency and customer tier. Delivers a monthly product feedback summary to the founder. Post-resolution $1–2
Escalation Agent When an issue is beyond autonomous resolution (billing disputes, complex bugs, feature requests requiring product decisions), packages the full context: customer profile, subscription tier, conversation history, diagnostic logs, and suggested resolution options. Delivers a clean brief to the founder via Slack or email so the response can be drafted in minutes. When Tier 1 can’t resolve $1–2

Support Flow Example

Scenario: A customer emails: “My intake emails aren’t sending.”

Step Agent Action
1 Triage Classifies as Technical · High Priority. Routes to Bug Detective.
2 Bug Detective Checks Supabase logs for send-intake-emails errors. Checks Resend delivery API. Checks attorney_profiles for valid email. Finds: Resend returned HTTP 429 (rate limit hit).
3 Tier 1 Responder Sends branded reply: “Hi [name], we identified a temporary delay in email delivery due to high volume. Your intakes are saved safely — emails will be delivered shortly. No action needed on your end.”
4 Analytics Agent Logs the incident. You receive a digest: “1 support ticket auto-resolved today. Resend rate limit at 2:14 PM — monitor if recurring.”

Time from customer email to resolution: <5 minutes. Human involvement: zero.

Agent Build Priority

Agents are built sequentially based on business impact. Support agents come first (retain customers), then marketing agents (acquire customers), then spinup agents (expand the portfolio).

Priority Agent(s) Team Rationale
1 Triage + Tier 1 Responder Support Immediate value once paying customers arrive. Reduces founder inbox from day one.
2 Content Writer + Ad Creative Marketing Drives customer acquisition. SEO content compounds over time — start early.
3 Schema Architect + Codebase Cloner Spinup Enables rapid vertical expansion. Unlocks the portfolio growth strategy.
4 Onboarding Coach + Churn Prevention Support Retention > acquisition once customer base exists. Prevents silent churn.
5 Ad Manager + Analytics Marketing Closes the autonomous marketing loop. Ads run and optimize without you.
6 Bug Detective + QA Agent Support / Spinup Completes the autonomous operations stack. Technical issues resolve faster.
7 All remaining agents All Full workforce operational. SEO, competitor watch, review solicitor, feedback, escalation.

Human-in-the-Loop Controls

Full automation is the goal, but the founder retains approval gates on high-stakes decisions:

Decision Agent Prepares Founder Approves
Ad campaign launch Creative, targeting, budget allocation staged One-click approval to go live
New vertical launch Everything built, tested, and ready Final “go / no-go” decision
Pricing changes Competitor data, margin analysis Always manual
Customer-facing copy (initially) Drafts ready for review Review and approve until trust is established
Escalated support tickets Full context package assembled Founder drafts response (with agent-suggested options)

Everything else runs autonomously. You wake up to a digest: “Here’s what your workforce did overnight: 3 support tickets resolved, 2 blog posts published, ad campaign ROAS improved 12%, 1 at-risk customer re-engaged.”
